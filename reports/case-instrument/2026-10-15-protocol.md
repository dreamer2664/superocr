# S70 preregistration — image-side case instrument v1 (t-20261014-479d)

Published BEFORE any dev or gate measurement. Frozen here; deviations

## Hypothesis

For tokens where the reader recovered every letter, wrong-case
decisions on **x-height twin letters** — shape-identical
lower/uppercase pairs — can be corrected from the IMAGE alone: the
renderer draws them at true x-height vs cap-height, so the glyph's
rendered height relative to the token's height anchors decides case.
Text-side case priors are already measured catastrophic (S55 §7 D: 1
fix vs 21+67 breaks); this instrument is image-side only and ABSTAINS
on ties.

## Twin set (frozen; may only narrow during dev, never widen)

o/O · c/C · s/S · v/V · w/W · x/X · z/Z

Anchor letters = every non-twin letter: their identity fixes their
height class by shape (e.g. reader says `e` → x-height, `T` → cap),
so the reader's own output provides the anchors even where its twin
case choices are wrong.

## Pipeline position and rule (frozen)

Runs AFTER the shipping route (floor + fix_line), per token:

1. Segment the image independently: ink mask + connected components;
   group into words by x-gaps. If a token's component count ≠ its
   letter count → ABSTAIN for that token (reader's answer kept).
2. Require baseline coherence: component bottoms within ±2 px of the
   token median bottom, else ABSTAIN.
3. Height anchors per token: x_ref = median height of components
   aligned to lowercase non-twin letters; cap_ref = median height of
   components aligned to uppercase non-twin letters.
4. Twin decision: with both anchors, mid = (x_ref + cap_ref)/2;
   h ≥ mid → uppercase, h < mid → lowercase; ABSTAIN if
   |h − mid| < 0.10 × (cap_ref − x_ref). With only one anchor class:
   decide against that anchor if the gap is ≥ 25% of it, else ABSTAIN.
   With no anchors: decide only if the token's component heights are
   clearly bimodal (max/min ≥ 1.35); taller cluster = cap, shorter =
   x; else ABSTAIN.
5. Flips change only twin-letter case; everything else untouched.
